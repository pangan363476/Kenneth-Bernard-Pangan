KENNETH BERNARD I. PANGAN — DIGITAL PORTFOLIO WEBSITE

HOW TO VIEW
1. Extract this ZIP file.
2. Open the folder.
3. Double-click index.html. It will open in your web browser.

HOW TO EDIT
- Open index.html in Visual Studio Code or another text editor.
- Update the text and styles as needed.
- Add project screenshots or certificate images when you have them.

HOW TO PUBLISH
You can upload this folder to a static website host such as GitHub Pages.
The main page is index.html.

NOTE
The website uses only HTML and CSS and does not need an installation or server to preview.
The contact section shows your email and phone number, so review whether you are comfortable
making those details public before publishing the site online.
